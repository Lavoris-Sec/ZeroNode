# ZeroNode 
**IoT Firmware Vulnerability Scanner & AI-Powered Audit Tool**

ZeroNode - это инструмент для разработчиков и инженеров кибербезопасности, предназначенный для автоматизированного поиска критических уязвимостей в прошивках IoT-устройств с использованием искусственного интеллекта.

## Основные функции (в разработке / MVP)
* Парсинг и анализ файлов прошивок (ARM-архитектура).
* Интеллектуальный поиск хардкодных учетных данных (например, admin:admin).
* Обнаружение открытых критических портов.
* Генерация понятных отчетов о безопасности устройства с подсказками от AI.
